
# Personal Developer Portfolio

## About the Project

This is my personal developer portfolio website, created to showcase my technical skills, projects, education, resume, and contact information.

The website is designed with a responsive layout so it works on desktop, tablet, and mobile devices.

## Features

- Responsive design for different screen sizes
- Mobile navigation menu
- Dark and light theme toggle
- Featured projects with popup descriptions
- Resume download option
- Contact form interface
- Smooth scrolling navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Project Structure

```text
developer-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── resume.pdf
```

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a web browser.
